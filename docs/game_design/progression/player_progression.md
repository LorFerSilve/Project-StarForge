# Player Progression

> **Status:** Design Complete  
> **Authority:** Cross-phase direct player capability progression without a Player Level

## 1. Core Rule

The player has no generic level, attribute-point tree, or automatic stat growth from mission XP.

Direct capability changes only through owned/installed equipment, tools, knowledge-enabled gear, and situational preparation.

## 2. Progression Axes

Player progression consists of:

- environmental survivability;
- combat options;
- portable storage;
- scanning/intelligence capability;
- mining/salvage/repair tools;
- mobility equipment;
- command capability for robots;
- consumable/loadout breadth.

## 3. P0

Starting capability supports:

- safe Horizon traversal;
- basic repair;
- basic mining/salvage;
- starter firearm/tool;
- limited hazardous-environment protection.

The player is not universally vacuum/anomaly/radiation capable at start.

## 4. P1

Reach I progression introduces reliable:

- sealed EVA-capable configuration;
- better backpack/containment;
- improved scanner;
- basic armor/shield options;
- broader ballistic tools/weapons;
- first robot command interface.

## 5. P2

Reach II introduces:

- specialized combat loadouts;
- improved personal shields;
- advanced environmental suit variants;
- energy weapon options;
- better scanner/hacking/repair gadgets;
- Command Link II/III progression access.

## 6. P3

Reach III introduces:

- advanced armor/energy protection;
- rail/plasma/high-end energy weapons;
- stronger field engineering tools;
- advanced hazard containment;
- high-capacity/specialized backpacks;
- Command Link III/IV access.

## 7. P4

Reach IV requires a configuration capable of Crownless/Verge environmental and mission demands.

This can include:

- advanced sealed suit;
- anomaly/radiation protection;
- suitable scanner/control tools;
- high-end combat/utility equipment.

The exact required loadout is capability-based, not one mandatory named armor set.

## 8. Equipment Sidegrades

Later equipment should present tradeoffs in:

- Mass;
- Volume/capacity;
- protection;
- Suit Energy;
- mobility;
- specialization;
- component/modification compatibility.

A higher-tech item is not automatically best for every mission.

## 9. Health

Normal player maximum Health does not increase because a campaign phase advances.

Additional survivability comes from real protection/medical capability unless an explicit biological augmentation system is later accepted.

## 10. Damage

Player outgoing damage is determined by actual weapon/ammunition/condition under GDS-9, not phase or hidden progression multiplier.

## 11. Environmental Capability

Mission environments can create hard equipment requirements.

Progression unlocks equipment able to satisfy those requirements rather than lowering the environment to the player.

## 12. Scanner Progression

Improved scanners can reveal more supported information, resolution, range, or analysis capability.

They never become universal wall-hacks/omniscience.

## 13. Tool Progression

Tool improvements can expand:

- mineable material class;
- salvage target capability;
- repair complexity;
- breach/access methods;
- action speed/efficiency.

They cannot bypass missing physical inputs or authorization where required.

## 14. Command Link Progression

Personal robot command equipment uses four capability tiers:

- Command Link I: base Personal TCC 2;
- Command Link II: base Personal TCC 4;
- Command Link III: base Personal TCC 6;
- Command Link IV: base Personal TCC 8.

These values are initial fixed first-pass capability targets and may be balance-tuned without changing the tier logic.

## 15. Command Link Acquisition Bands

- Link I: P1;
- Link II: P2 early;
- Link III: P2 late / P3 early;
- Link IV: P3 late / P4.

Research/Blueprint/equipment ownership is still required; phase alone does not grant the item.

## 16. No Skill Tree

The player does not unlock passive '+10% mining', '+5% damage', or '+20 Health' nodes from generic XP.

Equivalent improvements must be attached to a real system such as equipment, Research, tool design, crew/automation support, or ship/station capability.

## 17. Loadout Preparation

Progression increases options rather than allowing every option simultaneously.

Mass, Volume, equipment slots, Suit Energy, and mission environment force loadout tradeoffs.

## 18. Failure

Ordinary defeat does not remove committed player progression/knowledge.

Equipment can require repair; supplies can be consumed; unsecured loot can be lost.

## 19. Difficulty

All player progression is identical across Difficulty profiles.

## 20. Endgame

Postgame player advancement is continued access to alternative/high-end equipment configurations and remaining discoveries—not endless stat levels.

## 21. Explicit Non-Goals

No Player Level, stat points, prestige, difficulty-exclusive equipment, passive universal damage scaling, or generic perk tree.

## 22. Tuneable Parameters

Equipment statistics, Command Link TCC values, costs, masses, capacities, and unlock pacing are tuneable.

## 23. Dependencies

Depends on GDS-5 Equipment/Tools/Inventory, GDS-9 Combat, GDS-10 TCC, GDS-4 Research/Blueprints, Difficulty, and overall Progression Model.

## 24. Open Questions

None in the player progression baseline.
