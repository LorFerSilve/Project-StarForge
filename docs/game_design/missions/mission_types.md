# Mission Types

> **Status:** Draft  
> **Authority:** Canonical mission archetypes, their required gameplay verbs, valid objective families, and scope boundaries

## 1. Purpose

Mission Types provide reusable structures for authored and procedural expeditions.

A mission may combine compatible types but must declare one Primary Type.

## 2. Canonical Primary Types

Baseline mission types:

1. Resource Expedition;
2. Salvage Recovery;
3. Rescue;
4. Research / Anomaly Investigation;
5. Repair / Restoration;
6. Reconnaissance / Survey;
7. Recovery / Data Retrieval;
8. Defense;
9. Elimination / Suppression;
10. Escort / Transport;
11. Boarding Operation;
12. Mixed Expedition.

Full fortified-station Raids remain GDS-11 rather than ordinary GDS-8 missions.

## 3. Resource Expedition

Core verbs:

- locate;
- scan;
- mine/collect;
- secure;
- extract.

Typical objectives:

- acquire specified resource quantity;
- survey deposit;
- recover rare sample;
- fill extraction cargo target.

## 4. Salvage Recovery

Core verbs:

- locate wreck;
- secure site;
- diagnose;
- dismantle;
- transfer salvage;
- extract.

Typical objectives:

- recover named component;
- collect salvage quota;
- retrieve intact module;
- recover ship black box.

## 5. Rescue

Core verbs:

- locate survivor;
- reach/stabilize;
- remove local blocker;
- escort/transport;
- secure passenger;
- extract.

Typical blockers:

- hostile occupants;
- atmosphere failure;
- injury;
- locked access;
- damaged transport.

GDS-3 owns survivor identity/recruitment.

## 6. Research / Anomaly Investigation

Core verbs:

- scan;
- collect evidence;
- install/operate instruments;
- retrieve samples;
- survive environmental anomaly;
- secure data.

Rewards often include:

- Research Evidence;
- route information;
- unique samples;
- narrative flags.

## 7. Repair / Restoration

Core verbs:

- inspect;
- diagnose;
- acquire/bring parts;
- physically repair;
- power/restart;
- verify operation.

Targets can include:

- relay;
- habitat system;
- ship;
- station subsystem;
- navigation infrastructure.

Repair mechanics remain owned by the target system.

## 8. Reconnaissance / Survey

Core verbs:

- reach observation points;
- scan;
- identify threats/resources;
- map location;
- return/report.

Direct combat is optional unless generated by encounter state.

## 9. Recovery / Data Retrieval

Core verbs:

- locate;
- access;
- recover physical/data objective;
- secure;
- extract.

Examples:

- archive;
- black box;
- blueprint carrier;
- navigation record;
- mission-critical component.

## 10. Defense

Core verbs:

- prepare;
- protect;
- maintain critical target;
- repel threat;
- survive until success condition.

Defense can occur at:

- expedition facility;
- ship;
- survivor position;
- temporary mining site.

Home Station attack resolution belongs primarily to Station/GDS-11.

## 11. Elimination / Suppression

Core verbs:

- identify hostile target;
- engage;
- neutralize/disable;
- confirm objective;
- extract.

Possible targets:

- hostile patrol;
- dangerous machine;
- pirate leader;
- hostile wildlife nest;
- mission-specific ship.

GDS-9 owns combat behavior/damage.

## 12. Escort / Transport

Core verbs:

- receive entity/cargo;
- protect/move;
- maintain transport conditions;
- deliver to destination.

Escort can involve:

- survivor;
- convoy;
- scientific equipment;
- critical cargo.

## 13. Boarding Operation

Ordinary Boarding Operation covers a ship/small facility objective that does not use the full raid lifecycle.

Core verbs:

- approach;
- disable/access;
- board;
- complete interior objective;
- withdraw.

Large fortified station assaults with intelligence/external-defense/sabotage phases are GDS-11 Raids.

## 14. Mixed Expedition

Used when no single ordinary archetype captures the mission.

A Mixed Expedition must still list explicit component objectives.

It cannot become a license for undefined gameplay.

## 15. Secondary Type

A mission may add one or more Secondary Types.

Example:

Primary: Resource Expedition  
Secondary: Defense

Meaning:
- mining is the primary success purpose;
- the mining site must also be defended during an authored phase.

## 16. Story Missions

Story Missions use these same gameplay archetypes where possible.

Narrative identity does not exempt them from mission lifecycle, extraction, or physical ownership rules unless explicitly authored.

## 17. Faction Mission Profiles

Typical emphasis:

- Helios: Defense, Elimination, Escort, Recovery;
- Meridian: Resource, Salvage, Escort, Restoration;
- Asterion: Research, Recon, Recovery;
- Freehold: Rescue, Restoration, Defense;
- Blackwake: Boarding, Recovery, Elimination, illicit transport;
- Continuance: authentication, restoration, containment, hostile machine objectives.

Profiles are preferences, not exclusive restrictions.

## 18. Mission-Type Compatibility

Generator validates combinations.

Examples:

Valid:
- Resource + Defense;
- Rescue + Repair;
- Recon + Research;
- Boarding + Recovery.

Invalid unless specially authored:
- two mutually exclusive protected-target outcomes;
- escort target also required to be destroyed;
- secure intact module and destroy same module.

## 19. Direct Participation

Every baseline mission includes meaningful direct player involvement.

A mission cannot resolve solely because a station timer finished while the player never participates unless it is explicitly not an external mission.

## 20. Explicit Non-Goals

Mission Types do not provide:

- full GDS-11 station raids;
- pure menu-only combat resolution;
- type-specific alternate resource ownership;
- undefined hybrid mechanics.

## 21. Dependencies

This specification depends on Objectives, Zones, Generation, Exploration, Resources, Crew, Combat, Robots, Raids, and Narrative.

## 22. Open Questions

None in the mission-archetype baseline.
