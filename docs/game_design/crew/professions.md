# Crew Professions

> **Status:** Draft  
> **Authority:** Standard crew professions, their domain responsibilities, and the boundaries of professional capability

## 1. Purpose

Professions make recruitable crew mechanically distinct and tie people directly to station automation.

A profession defines expertise domain, not a rigid character class that prevents all cross-training.

## 2. Standard Profession Set

The baseline professions are:

- Farmer
- Engineer
- Mechanic
- Robotics Specialist
- Scientist
- Medic
- Security Officer
- Weapons Specialist
- Logistics Officer
- Navigator
- Intelligence Officer

## 3. Farmer

Primary domain:

- hydroponics and agriculture;
- crop scheduling;
- nutrient management;
- harvest automation;
- food-production fault detection.

A Farmer does not replace water, power, nutrients, or farming modules.

## 4. Engineer

Primary domain:

- power;
- atmosphere;
- oxygen;
- thermal systems;
- water utilities;
- structural/system diagnosis;
- infrastructure emergency response.

An Engineer is the main general station-infrastructure specialist.

## 5. Mechanic

Primary domain:

- mechanical machinery;
- docking equipment;
- spacecraft maintenance;
- non-electronic moving systems;
- heavy mechanical repair.

Mechanic overlaps with Engineer only where equipment combines disciplines.

## 6. Robotics Specialist

Primary domain:

- robot maintenance;
- drone fleets;
- robot production supervision;
- robot diagnostics;
- robotic automation capacity.

## 7. Scientist

Primary domain:

- research;
- artifact analysis;
- advanced technology;
- experimental systems;
- research-lab operation.

## 8. Medic

Primary domain:

- injury stabilization;
- treatment;
- recovery;
- medical facility operation;
- medical emergency response.

## 9. Security Officer

Primary domain:

- access policy;
- intrusion detection;
- lockdown;
- boarding response;
- internal security robot coordination.

## 10. Weapons Specialist

Primary domain:

- station weapon readiness;
- targeting policy;
- ammunition doctrine;
- defensive coordination;
- shield/weapon tactical management where defined.

## 11. Logistics Officer

Primary domain:

- storage policy;
- cargo routing;
- reserve management;
- supply priorities;
- blocked-flow diagnosis.

## 12. Navigator

Primary domain:

- route planning;
- travel preparation;
- navigation data;
- strategic movement efficiency;
- special-route capability where technology permits.

## 13. Intelligence Officer

Primary domain:

- enemy information;
- threat assessment;
- raid intelligence;
- faction information;
- sensor/intelligence analysis.

## 14. General Tasks

All healthy crew can perform basic non-specialist actions such as:

- evacuating;
- moving through the station;
- simple manual labor;
- using emergency equipment;
- following safety orders.

Specialized tasks require adequate skill/capability.

## 15. Primary Profession

Each crew member has one current primary profession.

A primary profession determines:

- default automation domain;
- training emphasis;
- assignment recommendations.

## 16. Secondary Skills

Crew can learn skills associated with other professions.

A crew member can therefore function as an emergency substitute if they meet the task's required skill threshold.

## 17. Profession Change

A permanent profession change is possible through sufficient cross-training and player reassignment.

It is not instantaneous.

The experience/progression specification owns transition requirements.

## 18. Unique Specialists

Authored characters can possess unusual combinations or special knowledge.

Special knowledge can unlock:

- research;
- dialogue;
- mission options;
- unique automation capability.

It does not bypass physical station requirements.

## 19. Profession Capacity

Professional capacity is finite.

A single expert can supervise more work than a novice, but not infinite modules.

Capacity is defined through assignments, skill, and automation infrastructure.

## 20. Profession UI

Crew interface shows:

- primary profession;
- skill levels;
- eligible assignments;
- current workload;
- capability gaps;
- training options.

## 21. Explicit Non-Goals

Professions are not combat classes and do not function as rarity tiers.

## 22. Dependencies

Professions depend on skills, assignments, automation responsibilities, station systems, research, spacecraft, robots, security, and narrative.

## 23. Open Questions

None in the current baseline.
