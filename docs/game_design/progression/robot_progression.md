# Robot Progression

> **Status:** Design Complete  
> **Authority:** Cross-phase robot class access, Tactical Control Capacity progression, platform support, manufacturing maturity, and robot fleet growth

## 1. Existing Authority

GDS-10 remains authoritative for Robot IDs, classes, components, Command Load, AI, manufacturing, deployment, damage, repair, and destruction.

This document defines progression bands and TCC capability growth.

## 2. No Robot Level

Robots do not gain generic levels or rarity tiers.

Progression comes from:

- chassis access;
- hardware;
- software;
- weapons/tools;
- energy systems;
- Research/Blueprints;
- manufacturing capability;
- command infrastructure.

## 3. Tactical Control Capacity Formula

For ordinary external deployment:

**Available Field TCC = Personal Command Capacity + strongest valid Platform Support + authored temporary support**

Normal external Field TCC is capped at **10**.

Finale-specific coalition support can raise the external cap to **12** when explicitly active.

## 4. Personal Command Capacity

Baseline Command Link tiers:

- Link I = 2 TCC;
- Link II = 4 TCC;
- Link III = 6 TCC;
- Link IV = 8 TCC.

The player must actually own/equip/operate the required command capability.

## 5. Platform Support

A compatible player spacecraft Command Support Module contributes **+2 TCC**.

Multiple ship support modules do not stack; only the strongest valid platform contribution applies.

## 6. Horizon Defense Support

While physically/logically linked to Horizon Station's operational Defense/Command Control, station support contributes up to **+4 TCC** instead of ship support.

Station and ship support do not stack.

Normal Horizon defense TCC cap is **12**.

## 7. Finale Support

An explicitly secured Coalition support commitment can provide **+2 temporary TCC** during MS-F02 where the mission support path is active.

The external finale cap is **12**.

This support does not manufacture robots or transport them; TCC and physical deployment remain separate.

## 8. P0

No mature tactical robot force is expected.

The player can encounter/repair automation but dedicated field squads are not required.

## 9. P1

Core unlock band:

- Recon Drone;
- Repair Drone;
- basic Assault Unit access by later P1;
- Robot Assembly Bay/basic service;
- Command Link I.

Focus is utility and small support rather than an army.

## 10. P2

Core unlock band expands to:

- Assault Unit;
- Hacker Unit;
- Shield Unit;
- Command Link II and later Link III;
- better sensors/armor/power;
- meaningful ship Robot Rack capacity.

## 11. P3

Core unlock band expands to:

- Breaching Unit;
- Demolition Unit;
- Heavy Mech;
- Advanced Robotics technology;
- high-end combat/support components;
- Command Link III/IV;
- Heavy Robot Bay access.

This is the phase where full strategic raid composition becomes mature.

## 12. P4

All baseline robot classes can be available if their Research/Blueprint/component requirements have been satisfied.

Focus shifts to:

- specialized configurations;
- energy/endurance;
- advanced shields/weapons;
- hardened communications;
- high-value support during Crownless operations.

## 13. Class Unlock Is Capability-Based

A phase defines intended availability, not free entitlement.

To deploy a class the player still needs:

- knowledge;
- Blueprint;
- manufacturing/service capability;
- physical robot;
- valid components;
- transport;
- TCC.

## 14. Fleet Growth

The player may own more robots than active TCC permits.

Progression increases strategic choices through:

- reserve fleet;
- station security force;
- specialized mission squads;
- replacement units;
- automation fleet.

## 15. Transport Growth

Field force growth requires actual ship support:

- Robot Racks;
- Heavy Robot Bay;
- charging;
- service;
- cargo/ammunition.

TCC alone cannot deploy robots from Horizon.

## 16. Component Progression

Later components improve real engineering capability such as:

- armor;
- sensors;
- energy reserve;
- communication resilience;
- weapon/tool access;
- shields;
- environmental resistance.

Tradeoffs in Mass/power/heat remain.

## 17. Robot Attrition

Destroyed robots remain destroyed in every phase.

Late progression improves replacement/repair capacity but never grants free resurrection.

## 18. Economy

Markets/factions can provide robot components/Blueprints/services where access permits.

Buying cannot bypass Advanced Robotics Research or required assembly infrastructure.

## 19. Difficulty

Difficulty does not change Command Load, TCC, robot physical stats, or permanent-destruction rule.

## 20. Postgame

Postgame robot progression emphasizes fleet specialization, redundancy, alternate faction technology, and optimized squad composition.

No endless robot level track exists.

## 21. Explicit Non-Goals

No generic Robot Level, rarity tiers, infinitely increasing TCC, summoning, free replacements, or TCC as currency.

## 22. Tuneable Parameters

TCC values/caps, unlock timing, recipes, component stats, charging/service capacity, and production pace are tuneable under the fixed formula/role structure.

## 23. Dependencies

Depends on GDS-10 Robots, Player/Spacecraft/Station Progression, Research/Blueprints, Raids, Economy, and Progression Model.

## 24. Open Questions

None in robot progression baseline.
