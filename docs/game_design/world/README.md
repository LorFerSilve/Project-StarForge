## Core Baseline

GDS-7 World establishes:

- The Fracture as the canonical post-collapse premise;
- game start in 67 AF;
- five strategic sector bands;
- a fixed campaign geography and route backbone;
- bounded planetary and space locations;
- six major factions;
- independent faction reputation;
- canonical hidden truth behind The Fracture;
- world-state persistence boundaries.

World documents define what exists and where it exists. Gameplay mechanics owned elsewhere are referenced rather than redefined.
